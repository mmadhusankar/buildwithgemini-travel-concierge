# My agent: travel-concierge
One-liner: A conversational agent that helps travelers discover hidden gems, plan day-by-day itineraries, and explore activities from a curated catalog of local destinations.

Tool coverage:
- Memory: User travel style, budget preferences, dietary restrictions, past trips, and preferred destinations
- Tools: Destination weather lookup, attraction search, and itinerary management
- Catalog/UI: Curated local spots, hotel/attraction cards, and day-by-day itinerary tables rendered as A2UI
- Image gen: Custom scenic destination postcards and visual itinerary previews
- Sandbox: Travel budget calculations and route transit estimations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for itinerary budget calculations, Google Maps API, Cloud Trace
